# 智慧影片逐字稿

一個以瀏覽器為工作台的影片逐字稿與大綱生成 MVP。

## 目前功能

- 本機上傳或直接影片檔網址：MP4、MKV、MOV、AVI、WEBM
- 影片長度與預覽
- Whisper 高精度模式：將影片音訊依固定秒數擷取並送出辨識
- 瀏覽器語音辨識模式：使用 Chrome／Edge 麥克風即時辨識
- 長影片分段、失敗重試、工作階段續作
- 時間戳記與可選說話者欄位
- 摘要、章節大綱、關鍵字
- TXT、Markdown、SRT、VTT、JSON 匯出

## 執行

這是純靜態前端。可用任何靜態伺服器開啟 `dist/`，例如：

```powershell
python -m http.server 4173 --directory dist
```

Whisper 模式需要在頁面輸入 OpenAI API Key；Key 只存在當前頁面記憶體，正式多人使用時應改由後端代理處理。

## 目前限制

- 網址匯入需是可直接播放／下載的影片檔網址；YouTube 或一般網頁頁面網址需要後端下載器。
- 瀏覽器語音辨識模式是即時麥克風模式，不會把任意影片的音訊直接餵給瀏覽器 SpeechRecognition API。
- MKV／部分遠端影片是否能在瀏覽器預覽與擷取，取決於瀏覽器解碼器與跨來源設定。
